# CELL-CELL COMMUNICATION ANALYSIS IN BREAST CANCER UNDER ANTI-PD-1 THERAPY

R scripts used for single-cell intercellular communication inference (CellChat v2) and longitudinal target gene expression analysis in ER+ and TNBC breast cancer cohorts treated with pembrolizumab.

## Repository Structure

- `01_CellChat.R`: Subgroup-level preprocessing (Seurat) and cell-cell communication inference (CellChat v2) for on-treatment ER+/E, ER+/NE, TNBC/E, and TNBC/NE cohorts.
- `02_Comparative_CellChat.R`: Differential intercellular communication and pathway information flow comparisons (`ER+/E vs. ER+/NE`, `TNBC/E vs. TNBC/NE`, and `ER+/E vs. TNBC/E`).
- `03_Target_Gene_Expression.R`: Per-patient longitudinal expression analysis (Pre- vs. On-treatment) using two-sided Wilcoxon rank-sum tests with Benjamini-Hochberg correction, effect sizes, and patient-level paired trajectories.

## Input Data

Raw count matrices and cell metadata were generated by Bassez et al. (2021) (BioKey clinical study, NCT03197389) and can be obtained from the Lambrechts Lab portal (http://biokey.lambrechtslab.org/).

To run the scripts, place the following files inside a `data/` directory in the repository root:
- `data/1863-counts_cells_cohort1.rds`
- `data/1872-BIOKEY_metaData_cohort1_web.csv`

## Software Requirements

- R (version ≥ v4.4.0)
- Seurat (v5.4.0)
- CellChat (v2.2.0)
- NMF (v0.28)
- ComplexHeatmap, ggplot2, dplyr, tidyr, patchwork, rstatix, ggpubr
